## 1. Application Title

Community Learning Center Management System

## 2. Description

This application is made using Dart. It helps manage learning resources and participants in a community learning center.

Users can add learning resources, register participants, borrow resources, and view all records.

## 3. Application Features

1. Add Learning Resource – Add a resource name and quantity.
2. Register Participant – Add a participant's name and contact number.
3. Borrow Learning Resource – Allow participants to borrow available resources.
4. View All Records – Show all resources and participants.
5. Exit – Close the application.
